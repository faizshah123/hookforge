Hooks are short on purpose. If a line is longer than 8–12 words, cut it before you film.

On-screen text is a layout problem

If the line wraps to four rows, nobody reads it. This CapCut text generator clips overlay copy so it can sit in the safe area above your face or hands.

Workflow: generate here → copy “On-screen” → CapCut Text tool → 2–3 word groups, high contrast, not over the TikTok UI. Then record voice that matches, not a different script.

Do not auto-caption secrets

Auto captions will happily subtitle a mumbled “um.” Write the overlay first so you are not editing 40 bad words later. More pacing notes: CapCut on-screen text tips.

FAQ

Does this connect to CapCut?

No. It never asks for a CapCut account. You paste text into the app yourself.

What font should I use?

Whatever you can read at arm’s length. High contrast beats a trendy script font.

Can I generate auto-captions?

We generate the lines you should show. CapCut still does speech-to-text on your voiceover.
