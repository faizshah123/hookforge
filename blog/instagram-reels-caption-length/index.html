Instagram Reels caption length (and what belongs in the first line)

Instagram truncates captions. If the first line is “Link in bio” you already lost the save. The video hook stops the thumb; the caption earns the bookmark.

A working shape

  1. First line: the same idea as the spoken hook, not a duplicate word-for-word if that looks spammy.
  2. Four to eight lines of useful detail a mute scroller can use later.
  3. One question that is answerable in a comment (“1 or 2?”).
  4. Hashtags last. A handful of true tags, not 30.

There is no magic character count. There is a magic job: be useful after the video ends. Generate a draft with the Reels caption generator, then cut anything you would not comment on a friend’s Reel.
