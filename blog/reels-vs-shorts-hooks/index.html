Reels vs Shorts hooks: what to change when you cross-post

The file can be the same. The first line often should not. Shorts viewers tolerate denser overlays. Reels viewers still read captions like a blog.

Change these three

  1. Overlay: Shorts can be blunter. Reels cover text has to look good on a grid.
  2. Caption: Reels wants a saveable paragraph. Shorts description can be shorter.
  3. CTA: Subscribe vs save vs follow. Do not say “link in bio” on a platform where that is weak.

Generate twice: Shorts and Reels. If you also ship TikTok, run TikTok as the spoken-first version.
